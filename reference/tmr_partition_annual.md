# Pre-built spatiotemporal partition (annual workflow)

Annual variant of `tmr_partition`. Built from points rarefied with
`time_cols = "year"` only (one point per pixel per year) and extracted
against annual predictors. Predictors attached to each point are
`forest_cover`, `pr_ann` (annual precipitation), and `elevation`, all
z-scored. Uses `n_spatial_folds = 2` and `n_temporal_folds = 2` for four
folds. Loaded with `data(tmr_partition_annual)`.

## Usage

``` r
tmr_partition_annual
```

## Format

A list as returned by
[`spatiotemporal_partition`](spatiotemporal_partition.md).
