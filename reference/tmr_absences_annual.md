# Pre-built pseudoabsence result (annual workflow)

Annual variant of `tmr_absences`. Buffer method with 300 m buffer and
2:1 ratio, generated against `tmr_partition_annual` with the annual
predictor set (`forest_cover`, `pr_ann`, `elevation`). Loaded with
`data(tmr_absences_annual)`.

## Usage

``` r
tmr_absences_annual
```

## Format

A list as returned by [`generate_absences`](generate_absences.md).

## Source

Generated by `data-raw/build_package_data.R`.
