# Pre-built spatiotemporal predictions (annual workflow)

Annual variant of `tmr_predictions`. Projects `tmr_glm_annual` across 15
years on a single (year-only) time axis. Loaded with
`data(tmr_predictions_annual)`.

## Usage

``` r
tmr_predictions_annual
```

## Format

A list as returned by
[`generate_spatiotemporal_predictions`](generate_spatiotemporal_predictions.md).

## Source

Generated by `data-raw/build_package_data.R`.
